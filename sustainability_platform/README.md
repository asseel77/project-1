# منصة مؤسسة الاستدامة (الموقع العام + لوحة التحكم)

تطبيق ويب متكامل مبني بلغة **Python** وقاعدة بيانات **SQLite**، منفذ وفق الخطة النظرية المعتمدة للمشروع.

## التشغيل السريع
لا يتطلب المشروع تثبيت أي مكتبات خارجية (يعتمد على مكتبات Python القياسية فقط):

```bash
python app.py
```

ثم افتح المتصفح على:
- **الموقع العام:** http://127.0.0.1:8000
- **لوحة التحكم:** http://127.0.0.1:8000/admin

## بيانات الدخول الافتراضية
- **المدير العام (Admin):** `admin@estidama.sa` / `Admin@123`
- **المحرر (Editor):** `editor@estidama.sa` / `Editor@123`

## هيكل المشروع
- `app.py`: الخادم والتوجيه، إدارة الجلسات والصلاحيات (RBAC)، ومعالجة الطلبات والملفات.
- `db.py`: إنشاء جداول قاعدة البيانات العلائقية (SQLite) والبيانات الأولية.
- `views.py`: قوالب HTML للصفحات الست ولوحة التحكم مع الحماية ضد XSS.
- `static/`: ملفات التنسيق CSS والشعارات والملفات المرفوعة.
- `database.db`: قاعدة البيانات الفعلية.

**إعداد الطالب:** أصيل باسم السنوسي
